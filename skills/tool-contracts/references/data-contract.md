# 데이터 읽기와 입출력 계약

표·배열·시계열 파일을 처음 읽거나 변환·결합·집계 경계를 설계·변경할 때 읽는다. 기존 계약이 유효하면 재작성하지 않는다. 아래 항목은 현재 도구 명세에 합쳐 기록하며 별도의 병렬 상태 문서를 만들지 않는다.

현업 DM에서 확인한 데이터 설명에는 답변 위치·적용 범위를 연결하고 실제 파일의 구조·값과 대조한다. DM 확인과 데이터 검증을 구분하며, 불일치는 의미·버전 차이를 확인할 때까지 충돌·미확정으로 남긴다. 설명에 맞추려고 원본을 고치거나 중복을 임의로 지우지 않는다.

- 형식·인코딩·시트/배열 경로·축 의미·열 순서·자료형을 확인한다. 길이가 다른 레코드를 같은 길이라고 가정하거나 1행짜리 배열의 축을 자동으로 없애지 않는다. 레코드 ID와 원본 행/열 위치를 남긴다.
- 시간값의 의미·단위·해상도·정렬 기준을 확인한다. 원본 순서를 보존하고 역행/중복을 관찰 사실로 기록한다. 근거 없이 정렬·보간·타이머 리셋 판정으로 고치지 않는다.
- 식별자/그룹 키의 동일성, 시간 감소·중복의 비교 규칙, 출력 통계의 허용오차를 구분한다. 통계 대조용 허용오차를 키 병합이나 시간 중복 판단에 자동 적용하지 않는다. 도메인 해상도가 확인되면 입력 규칙과 검증에 같은 기준을 명시한다. 미상 단위·고장 시작점·원인 라벨을 만들어내지 않는다.

- 한 행의 의미, 식별자와 집계 키, 단위·기간·시간대를 먼저 정한다. 식별자 앞자리 0과 원본 값은 보존한다. 행 단위가 다른 자료를 같은 단위인 것처럼 합치지 않는다.
- 결합 키마다 기대 카디널리티(일대일·다대일 등)를 명세한다. 실제 키별 빈도와 미등록 키를 확인한다. 중복 시 합산·최신 버전 선택·보류 중 무엇이 맞는지 출처와 업무 규칙으로 정한다. DISTINCT나 첫 행 선택으로 모호성을 덮지 않는다.
- 결측·실제 0·분모 0·형식 오류·정상적인 조회 없음의 표현을 구분한다. 빈 값을 무조건 0으로 바꾸지 않는다. 정제 값과 원본 값을 추적할 수 있게 한다.
- 비율은 분자·분모·동일 모집단을 정의한다. 전체 비율과 행별 비율의 평균 중 요구하는 지표를 명시한다. 반올림은 표시 단계에서 한다.
- 보류·제외 기준과 사유 보존 방식을 정한다. 검증된 일부 행만 집계했다면 해당 모집단·누락 범위를 결과에 표시한다. 미확인 값을 포함한 완전한 전체 합계를 주장하지 않는다.
- 원본을 덮어쓰지 않는 출력 경계를 정하고 결합 전후 행 수·가산량이 달라질 수 있는 조건을 계약에 적는다. 전체 원본을 읽어 계산한다.

변환이 필요하면 원본/변환 파일의 버전과 복원·대조 방법을 먼저 정한다. LLM에는 검증된 스키마·요약·원천 위치와 필요한 구간을 제공한다. 원시 파일의 미리보기나 정규화 메타데이터의 행 수만으로 전체 파싱이 검증됐다고 보지 않는다. 전체 입력 처리와 LLM 문맥에 모든 값을 넣는 것은 구분한다.

도구 단계는 이 계약의 타입·예외·단독 동작을 확인한다. 전체 결과의 골든셋·독립 계산·모집단 대조는 결과 검증 단계에서 한 번 수행한다. 특정 과제의 보류 정책·숫자·업종별 임계값은 이 공통 지침에 고정하지 않는다.
