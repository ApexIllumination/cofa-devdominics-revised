# 도구와 데이터 계약

표·배열·시계열 파일을 새로 읽거나 결합·집계 경계를 변경한다면 [데이터 계약 참조](references/data-contract.md)를 필요한 범위에서 읽는다.

1. 현재 도구·명세·접근 경로를 확인한다. 이미 검증됐고 변경되지 않은 경계는 재사용한다. 부족한 기능에만 새 도구를 추가한다.
2. 입력 타입·필수값, 반환값, 정상 조회 없음·형식 오류·실행 오류, 자료 출처·버전을 명세한다. 설명에 입력·반환·사용 시점을 적는다.
3. 전체 집계는 전체 원본을 코드·계산 도구로 읽는다. 미리보기로 전체 합계를 만들지 않는다. 날짜·단위·식별자·분모·누락을 확인하고 기준값 0·기간 차이를 처리한다.
4. 새로 만들거나 변경한 경계의 정상·미등록·형식 오류 중 필요한 사례로 단독 검증한다. 결과와 버전을 검증 단계에 넘기고 전체 흐름 검증을 반복하지 않는다.

도구 관련 상태만 기존 기록에 갱신한다. 0·누락·정상적인 조회 없음·실행 오류를 구분하고 빈 값을 지어내지 않는다. 실제 도구·접근 권한과 확인한 동작까지만 보고한다. 외부 부작용의 실행·재실행은 현재 권한과 환경을 따른다.

## MCP를 새로 쓰거나 연결 조건이 바뀔 때만

기존 CLI·파일 읽기로 충분하면 이 점검을 건너뛴다. MCP가 필요한 경우 아래에서 아직 확인되지 않은 항목만 점검하고, 검증한 연결은 조건이 바뀌기 전까지 재사용한다.

- **필요성:** 기존 도구로 부족한 기능과 MCP 사용의 이익을 확인한다.
- **권한·전송:** 접근 대상, 외부로 전송되는 데이터와 목적지, 읽기·쓰기 권한을 확인한다. 공개 서버나 연결 가능 상태만으로 사용 허용을 판단하지 않는다. 시험의 허용 범위는 EXAM.md와 현재 안내를 따른다.
- **작은 검증:** 허용된 스키마 조회·소량 조회로 응답 구조, 단위, 누락, 페이지 처리·잘림 여부를 확인한다. 전체 집계 전에 필요한 범위를 모두 읽었는지 확인한다. 연결 시험을 위해 쓰기 작업을 실행하지 않는다.
- **근거:** 출처, 조회 조건·시각, 확인한 범위와 미확인을 기존 과제 기록에 남긴다.
- **대체 경로:** 연결 실패나 권한 불명확 시 같은 시도를 반복하지 않고, 허용된 제공 파일·기존 도구로 진행하거나 필요한 확인을 요청한다. 실패한 쓰기는 실제 반영 여부를 확인하기 전 재실행하지 않는다.
