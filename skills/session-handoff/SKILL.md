# 세션 인수인계

기존 과제 기록을 사용한다. 없고 실제 인계가 필요할 때만 위치 하나를 정한다. 아래 항목은 빠진 정보를 보완하는 기준이며 별도 문서를 복제하라는 뜻이 아니다.

- 목표·완료 조건·현재 동작 범위·주요 결정과 이유
- 핵심 파일·진입점·실행 명령·필요한 설정
- 유효한 검증·실패·미실행의 근거 위치
- 실행 중 작업·남은 위험·다음 구체적 행동
- 사용하는 구조 지도·기준 지문, 과제 골든셋·최근 평가 결과 위치와 현재 단계

기존 결정·검증 항목과 로그는 재사용하고 재개 정보만 보완한다. 비밀값 대신 설정 이름과 획득 경로를 적는다. 동시 작업에서는 통합 주체를 정해 공유 기록의 갱신을 직렬화한다.

재개할 때 기록을 실제 파일·실행 상태와 대조한다. 불일치는 마지막 변경과 근거를 확인해 해소하며 오래된 기록을 현재 사실로 가정하지 않는다. 대화 전체나 같은 상태를 여러 문서로 복제하지 않는다.

구조 지도가 설정되어 있으면 시작 변경 검사 결과를 먼저 확인한다. 지도나 기준 지문을 단순히 새 세션이 시작됐다는 이유로 자동 갱신하지 않는다. 지도가 없는 짧은 작업에 새 구조 문서를 필수로 요구하지 않는다.
