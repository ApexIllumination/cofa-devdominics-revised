# 과제 상태

이 파일은 빈 양식이며 현재 과제의 실행 기록이 아니다. 기존 과제 상태 파일이 있다면 그것을 사용하고, 없다면 지속 작업에 필요한 경우에만 위치 하나를 정해 필요한 항목을 옮긴다. 빈 항목을 채우기 위해 사실이나 수치를 만들지 않는다. 결정·검증·인계마다 같은 상태를 별도 문서로 복제하지 않는다.

- 현재 과제와 기록 기준 시점:
- 현재 단계(과제 작업/제출 준비/확정 후)와 작업·최종 종료 시각:
- 공유 기록을 통합하는 주체(동시 작업할 때):

## 목적과 범위

- 사용자·상황·문제:
- 핵심 결과와 수용 조건:
- 필수 / 선택 / 제외:
- 확인된 제약:
- 가정과 남은 질문(영향받는 결정·의존 작업·다음 확인):
- 필수 제출 파일·경로와 저장 확인:

## 구조와 평가 자료의 위치

- 구조 지도·기준 지문·최근 변경 검사 결과:
- 과제별 골든셋·입력 자료 버전·기대값 근거:
- 최근 평가 결과와 실행 범위(전체·선택 사례):

| --- | --- | --- | --- | --- | --- |

조건을 실제로 확인했을 때만 검증완료로 전환한다. 이 표가 진행 상태의 기준이며 별도 roadmap·phase 문서에 같은 상태를 반복하지 않는다. 실패 단계에 의존하지 않는 작업은 계속할 수 있다.

여러 단계의 결과를 연결할 때만 각 단계에 필요한 항목을 보완한다. 기존 계약·검증은 위치로 연결하고 별도 표를 중복 생성하지 않는다.

- 선행 단계·입력 경로/버전 → 처리 주체 → 출력 경로:
- 완료 검증·통과 범위 / 실패·미확인:
- 실패·변경 시 복구할 단계와 중단 조건:
- 병렬 실행 시 예상 분기·누락·병합 조건:
- 사람이 결정할 사항과 영향받는 작업(필요할 때):

현업 답변을 사용했다면 위치/시각·버전과 필요한 원자료 근거를 연결한다. 기존 기준 진술·새 합의·가정·미확정·충돌을 구분하고, DM 확인과 실제 자료 검증을 별도로 표시한다. 같은 대화를 별도 인터뷰 문서로 복제하지 않으며 답변 없음은 합의가 아니다.
